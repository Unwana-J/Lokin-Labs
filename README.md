## 🎨 Design Philosophy & Architectural Rules

- **Zero "AI Bubble" Pills**: Strictly architectural lines, delicate 1px dividers, and monospaced technical metadata.
- **Color Architecture**:
  - Crisp Gallery White (`#FFFFFF`) and Neutral Card Surfaces (`#F8F9FA`)
  - Deep Obsidian Black (`#090A0E`) for focal sections
  - High-contrast Purposeful Accent: Terracotta Crimson (`#9B283A`)
- **Studio Leadership**: Founded and led by **Unwana John-King**.
- **Official Inquiries**: `letslokin@gmail.com`

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans & IBM Plex Mono
